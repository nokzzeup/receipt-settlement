# dataset — 테스트 영수증 + 정답 라벨

OCR·파싱 정확도 측정과 파서·전처리 개선에 쓰는 데이터. 수집·라벨링 담당: 김도현

채점: 레포 맨 위에서 `npm run ocr:eval` (자세한 옵션은 README "실제 OCR")

```
dataset/
  images/     영수증 원본 사진   ← git에 올리지 않음 (.gitignore). 팀 드라이브에서 받아서 여기에 둘 것
  labels/     정답 라벨(JSON)    ← git에 올림
  ocr-cache/  채점 도구가 저장하는 OCR 결과 (마스킹 후) ← 자동 생성, git 제외
```

- 파일 이름은 이미지와 라벨을 1:1로 맞춘다: `images/r0001.jpg` ↔ `labels/r0001.json`
- 원본 사진에는 카드번호 일부·승인번호 등이 찍혀 있으므로 레포(특히 공개 레포)에 올리지 않는다

## 라벨 형식 = `ReceiptFields` (backend/app/parsing/schemas.py와 동일)

```json
{
  "store_name": "행복마트 테스트점",
  "paid_at": "2026-09-28T14:32:05+09:00",
  "total_amount": 25400,
  "items": [
    { "name": "생수 2L", "quantity": 2, "unit_price": 1200, "amount": 2400 },
    { "name": "A4용지 500매", "quantity": 1, "unit_price": 6500, "amount": 6500 }
  ]
}
```

- 금액·수량은 정수(쉼표·"원" 없이), 시각은 `+09:00`을 붙인 ISO 형식
- 영수증에 없는 값은 `null` (예: 단가가 안 찍힌 영수증 → `"unit_price": null`)
- 품목 이름은 영수증에 찍힌 그대로 (오타·약어 포함) — 사람이 보기 좋게 고치지 않는다
- 할인 줄은 음수 금액 품목으로 (`{"name": "행사할인", "quantity": 1, "unit_price": null, "amount": -1000}`)
- 채점할 때 가게명·품목명의 **띄어쓰기는 무시**하고, 결제일시는 분 단위까지, 단가는 채점하지 않는다

## 수집 팁
- 편의점 / 마트 / 식당 / 카페 / 문구점 등 업종을 섞고, 감열지가 바랜 것·구겨진 것·기울여 찍은 것도 포함
- 같은 영수증을 조건(조명·각도)만 바꿔 여러 장 찍어두면 전처리 효과 비교에 좋음
